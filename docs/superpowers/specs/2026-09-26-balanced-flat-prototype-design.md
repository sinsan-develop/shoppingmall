# 어울몰 균형형 Flat 시안 설계

- 상태: 신산님이 시각 비교에서 방향을 승인, 정본 파일 및 구현 계획 검토 전
- 범위: 검토용 고객·판매자·관리자 클릭형 시안의 시각 표현. 제품 기능·데이터·권한·거래 규칙은 변경하지 않는다.

## 목적과 기준

어울몰의 황금 `#c79a3e`·크림·먹빛, 고운바탕 제목·가격, Noto Sans KR 본문·UI, 기존 화면 정보 구조와 글자 크기를 유지하면서 입체 장식을 줄인다. 상품 사진은 평면 일러스트로 바꾸지 않는다. 신산님이 검토한 대표 요소는 고객 상품 카드, 판매자 재고 입력, 관리자 프로모션이다.

## 시각 규칙

- 페이지와 패널은 단색 표면 및 얇은 경계선으로 구분한다. 카드·패널 그림자와 hover 상승 효과를 제거한다.
- 카드·패널 모서리는 8px, 일반 버튼·입력은 6px을 기본 후보로 둔다. pill은 짧은 상태 표시 등 필요한 요소에만 둔다.
- 주요 버튼은 단색 황금, 보조 버튼은 얇은 테두리로 나타낸다. hover·press는 색·경계선으로 나타내고 위치 이동은 사용하지 않는다.
- 상품 사진과 원산지·가격의 정보 위계는 유지한다. 히어로의 장식용 광택·방사형 그라데이션은 단색 크림 면으로 대체한다.
- 업무 화면의 선택 메뉴는 떠 있는 카드 대신 단색·선·문구로 나타낸다. 상태는 색상만으로 구분하지 않고 텍스트를 함께 둔다.

## 적용·보존 경계

- 승인된 정적 시안 v1과 현재 클릭형 시안은 덮어쓰지 않는다. 별도 Flat v2 비교본에서 세 역할의 동일 흐름을 확인한다.
- 할인·프로모션 값은 시안 예시일 뿐 실제 결제·정산·고객 공개 규칙을 바꾸지 않는다.
- 글자 크기 기준은 현행 `docs/design/DESIGN.md`의 PC·모바일 본문 12px, 주요 제목 18px, 상품명 13px, 가격 14px, 모바일 주요 입력 16px을 따른다.
- 실제 제품 디자인 토큰·컴포넌트·DB·API·브랜치·원격·WSL 시험은 이 시안 변경에 포함하지 않는다.

## 검토와 검증

- 기존/Flat v2를 1920×1080, 1440×900, 430×844에서 비교한다.
- 키보드 focus, 색·텍스트 상태 구분, 입력 label, 200% 확대, 상품 카드·폼·표의 넘침을 확인한다.
- 정적 검사와 실제 브라우저 확인을 구분해 기록한다. 실제 브라우저가 차단되면 완료로 표시하지 않는다.
- 신산님이 Flat v2 시안을 검토한 뒤 확정 여부를 결정하며, 그전에는 기존 v1을 승인본으로 유지한다.
