# 어울몰 역할별 독립 클릭형 시안

아래 HTML 파일을 각각 열어 검토해 주세요. 세 화면은 서로 연결되지 않고, 새로고침하거나 상단의 **처음부터 다시 보기**를 누르면 해당 화면만 초기화됩니다. 예시 이름·금액·주문·운송장·정산 자료는 모두 가상입니다.

| 역할 | 시작 파일 | 눌러 볼 순서 |
|---|---|---|
| 고객 | [고객 시안](customer.html) | 상품에서 수량을 입력해 고추·양파·마늘 담기 → 장바구니에서 수량 변경·상품 제거 및 단가×수량 확인 → 결제 확인(각 1개면 발송 주문 3개, 통합 금액 101,000원) → 모의 결제 실패/성공 → 주문별 출고 전 취소. 품절 블루베리는 담을 수 없습니다. 고추 예시 할인 5,000원은 1개당 적용합니다. |
| 판매자 | [판매자 시안](seller.html) | 배송 정책 요청(승인 전 공개 기준 유지) → 변경할 재고 수량을 직접 입력. 18→5개 또는 0개는 즉시 반영되고, 18→20개나 품절 해제는 승인 대기 → 가상 운송장으로 출고 처리. |
| 관리자 | [관리자 시안](admin.html) | 판매자 요청 승인/반려 → 출고 전 농가 B 주문 환불(상품 30,000원+배송비 3,000원) → 농가별 또는 전체 기간 조회 → ‘조회 결과 인쇄 / PDF 저장’으로 브라우저 인쇄 창 열기. 전체 조회에는 농가별 내역과 전체 합계가 포함되며 정산 완료는 농가별로만 처리합니다. 기본 농가 A 기간은 이미 완료되어 중복 완료가 막히므로 농가 B를 선택해 완료를 시험해 보세요. 시작일·종료일을 모두 7월 1일로 바꾸면 농가 A의 환불 47,000원과 5월 1일 원판매 주문 연결을 볼 수 있습니다. |

고객·판매자·관리자 화면은 독립된 사례입니다. 한 화면에서 승인·취소해도 다른 화면에는 전파되지 않습니다. 이 시안은 화면 흐름과 정책 이해를 위한 자료이며 실제 계정·권한 검사·DB·재고 변경·실제 결제·환불·송금·발송·고객 알림을 수행하지 않습니다. 출고 후 환불액과 배송비·반송비는 법률·약관 검토 전 미확정이라 자동 계산하지 않습니다.

PDF는 파일을 직접 생성·자동 다운로드하지 않습니다. 인쇄 창의 대상에서 **‘PDF로 저장’**을 선택해 파일을 저장하거나 프린터를 선택해 출력해 주세요. 인쇄 내용은 마지막으로 **조회한** 기간과 대상의 가상 정산 자료입니다. 필터 값만 바꾸고 조회하지 않으면 직전 조회 결과가 출력됩니다.

Node 모델·화면 연결 검사와 글자 크기 검사는 통과했습니다. **실제 브라우저 렌더링·버튼 클릭·인쇄/PDF 저장·모바일 반응형·200% 확대·키보드 흐름은 미검증**입니다. 시안을 열 때 화면이 비거나 버튼이 반응하지 않으면 파일과 사용한 브라우저를 알려 주세요. 검토 후 수정 의견 또는 시안 승인 여부를 결정해 주세요.
