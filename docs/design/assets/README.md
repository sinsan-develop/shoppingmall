# 어울몰 정적 화면 시안 v1

이 폴더의 HTML은 디자인·정보 배치 검토용입니다. 상품·가격·재고·주문·고객 정보는 가상 자료이고, 버튼은 동작하지 않습니다. CSS는 같은 폴더의 `owool-static-v1.css`를 공유합니다. 실제 결제·계정·관리자 권한 기능은 포함하지 않습니다.

Windows 파일 탐색기에서 원하는 `.html` 파일을 브라우저로 열어 화면을 확인할 수 있습니다. Google Fonts를 불러오지 못하면 시스템 한글 서체로 대체되므로 서체의 최종 품질은 실구현 화면에서 다시 확인해야 합니다.

폰트 **크기**는 `cyhuh7950/owoolmall`의 `main` 커밋 `6cc92c0`을 참조해 본문 12px, 주요 제목 18px, 상품명 13px, 가격 14px로 조정했습니다. 기존 서체·색상은 바꾸지 않았습니다. 모바일 주요 입력만 가독성을 위해 16px를 사용합니다. 정적 검사는 `node --test docs/design/assets/typography.test.cjs`로 실행할 수 있으며 실제 브라우저 화면 검증을 대신하지 않습니다.

| 화면 ID | 파일 | 확인할 내용 |
|---|---|---|
| H-01 | [고객 홈](home-v1.html) | 어울몰 이름, 황금·크림 톤, 지역 제한 없는 산지 표현, 제철 상품·농가 정보 |
| C-01 | [결제 확인](checkout-v1.html) | 농가별·어울몰 발송 주문 분리, 발송 주문별 무료배송, 한 번에 결제할 합계 |
| S-01 | [판매자 업무](seller-v1.html) | 동일 판매자 절차, 자기 담당 범위, 변경 요청의 승인 대기, 품절 즉시 차단·출고 즉시 공개 |
| A-01 | [관리자 업무](admin-v1.html) | 판매자 요청 승인, 관리자 환불 결정, 농가별 기간 정산 자료·개별 완료 |
