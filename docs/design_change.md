## Task 4 — 공유 WSL 30분 부하 실행 창

- 판정: 현재 공유 WSL 자원에서 100 동시 사용자·30분 부하는 실행하지 않는다. 읽기 시점 2 vCPU의 load average 4.95/7.06/6.41, swap 사용 5.0/8.0 GiB이고 다른 서비스 컨테이너가 다수 실행 중이다. `k6` 실행 파일과 SeaweedFS 4.47 이미지는 확인되지 않았다.
- 영향: 계획의 30분 p95·5xx·주문/재고/정산 정합성은 미검증. 기존 서비스의 성능 저하를 피하기 위해 보호 `shoppingmall` DB 및 공유 서비스에 부하를 걸지 않았다.
- 조치/재개 조건: 독립 로컬·격리 1사용자 smoke와 도구/자원 준비를 먼저 진행한다. 공유 시험 전 실제 한가한 시간대에 CPU·swap·디스크·서비스 영향을 재측정하고 정확한 대상 SHA·QA DB ID·자동 중단 임계치·복구 경계를 기록한 뒤 계획 A4의 환경별 실행 승인을 대조한다. 서버가 계속 바쁘면 별도 격리 환경 시험만 부분 증거로 유지한다.
