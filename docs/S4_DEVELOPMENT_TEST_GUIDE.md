# 어울몰 결제·취소·환불 개발시험 안내 (S4)

이 안내는 개발용 가상 계정과 모의 결제에서만 사용합니다. 실제 카드 청구·송금·PG 환불은 일어나지 않습니다. 운영 환경 또는 사용자 인수테스트의 합격 안내가 아닙니다.

## 준비

- 담당자가 전달한 고유 가상 계정(구매자·운영자), 시험 비밀번호, 접속 주소만 사용합니다. 비밀번호는 문서나 화면 캡처에 남기지 않습니다.
- 개발용 결제 버튼은 WSL 시험 서비스의 로컬 연결에서만 나타납니다. 버튼이 없다면 운영 서비스에서 시험하지 말고 담당자에게 환경을 확인받습니다.
- 가상 상품·주문은 시험이 끝나면 해당 시험 ID로만 정리합니다. 이미 존재하는 다른 계정이나 상품을 시험용으로 바꾸지 않습니다.

## 구매자: 주문과 모의 결제

1. `/login`에서 접속 역할 **구매자**를 고르고 가상 계정으로 로그인합니다.
2. 상품을 장바구니에 담고 `/cart`에서 수량·상품금액과 발송 주문별 배송비를 확인합니다. 수량 변경·제거는 예약 전에 합니다.
3. **결제 준비 · 15분 재고 예약**을 누릅니다. 배송지를 확인한 뒤 **결제대기 주문 생성**을 누릅니다. 이 단계는 결제 완료가 아닙니다.
4. 개발 시험용 **모의 결제**의 결과를 거절 또는 지연으로 골라 누르면 주문은 아직 결제대기입니다. 새 시도로 승인 결과를 선택할 수 있습니다.
5. **모의 결제 승인 시험** 후 결제완료 문구와 본인 주문을 확인합니다. 연결이 끊겨 응답을 못 봤다면 같은 선택으로 다시 확인합니다. 고객 화면 복귀만으로 결제완료가 되지 않습니다.

## 구매자·운영자: 출고 전 취소·환불

1. 구매자는 `/cart`의 **이전 결제완료 주문**에서 본인 주문을 선택합니다. **취소 수량**과 사유를 입력해 **환불 요청**을 누르고 접수 이력을 확인합니다.
2. 운영자는 `/login`에서 접속 역할 **운영자**로 로그인하고 `/account/admin/refunds`에서 요청을 고릅니다. 실제 출고 전임을 확인한 뒤 **출고 전 미발송 확인**에 표시하고 재고 처리와 승인 사유를 입력해 **승인·모의 환불 실행**을 누르거나 사유를 적어 **반려**합니다.
3. 구매자는 같은 주문의 처리 이력을 다시 확인합니다. 일부 수량만 취소하면 해당 상품의 실제 결제금액만 환불하고 배송비를 새로 청구하지 않습니다. 마지막 남은 수량까지 취소한 발송 주문은 실제 납부한 배송비를 한 번 포함합니다. 다른 발송 주문은 그대로 유지됩니다.

## 확인할 결과와 한계

- 이 시험의 가상 예: 상품 12,000원 − 할인 2,000원 + 배송비 3,000원 − 배송비 지원 1,000원 = 결제 12,000원. 3개 중 1개 부분 취소 3,333원(배송비 0원), 남은 2개 전량 취소 8,667원(상품 6,667원 + 실납 배송비 2,000원)입니다.
- 판매자는 운영자의 환불 승인·실행을 할 수 없습니다. 출고 후 교환·반품/증빙 심사는 S5.2 이후 시험합니다.
- 주문번호·화면 시각·상태가 다르거나 결과 확인이 어려우면 임의로 다른 주문을 취소하거나 시험자료를 삭제하지 말고 담당자에게 전달합니다. 실제 PG·카드·Oracle·최종 약관은 별도 인수/출시 단계에서 검증합니다.
