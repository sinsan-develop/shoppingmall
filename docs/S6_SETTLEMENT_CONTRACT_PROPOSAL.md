# S6 정산 계약 제안 — 승인 전 검토본

- 기준: `docs/design/DESIGN.md` R09, `docs/PRD.md` 8.4, `docs/WORK_PLAN.md` S6.1·S6.2.
- 상태: 신규 DB schema/migration·권한·공개 API는 **미승인**. 이 문서는 구현·공유 DB 적용 승인이 아니다.

## 확인된 원자료

| 항목 | 현재 원자료 | 정산에 필요한 연결 |
|---|---|---|
| 판매 상품·할인 | `shipment_order_lines`의 상품/옵션·판매자·수량·할인 스냅샷 | `checkout_orders.paid_at` 및 승인·적용된 `payment_events`에 연결 |
| 발송 주문 배송비·지원 | `shipment_orders`의 배송비·지원 금액 | 발송 담당 판매자와 원 생산 판매자를 구분 |
| 환불 | `refund_events`의 적용 사건, `refund_cases`의 완료시각·원주문, `refund_case_lines`의 품목별 금액 | 환불 발생일에 기록하고 원 판매 상품·주문을 링크 |
| 판매자 분류 | 현재 `sellers.category_id` | 발생 당시 분류를 보존해야 과거 집계가 바뀌지 않음 |
| 수수료 | 현재 주문·결제 schema에 수수료 원천 금액 없음 | 자동 계산하지 않고 관리자가 근거·시각을 입력하는 별도 발생 기록이 필요 |

## 권장 계약(별도 승인 필요)

1. **불변 발생 장부:** 신규 `settlement_events`에 항목 종류(매출·수수료·배송비·할인·배송비 지원·환불), 원화 금액, 발생 시각, 판매자와 당시 분류 스냅샷, 원결제/환불·원주문·발송 주문·상품/옵션 근거를 저장한다. 동일 원사건·판매자·항목·품목의 중복 기록을 DB 제약으로 막는다. 오류는 기존 행 덮어쓰기 대신 사유 있는 정정 사건으로 남긴다. 배송비는 발송 담당 판매자, 상품 매출/할인/환불은 원 생산 판매자 근거를 유지한다. 수수료는 관리자 입력 사건으로만 기록하며 지급액의 가산·차감은 정하지 않는다.
2. **개별 완료 이력:** 신규 `seller_settlement_periods`에 판매자·시작일·종료일·완료 담당 관리자·시각·근거를 기록하고, 같은 판매자의 완료 기간 중복을 DB 트랜잭션에서 막는다. 서로 다른 판매자는 독립 처리한다. 완료 후 발생한 환불은 새 기간에 남기고 과거 완료 기록을 소급 변경하지 않는다.
3. **접근 계약:** 관리자만 전체/분류/판매자·임의 기간 발생 기록 조회와 판매자 한 명의 기간 완료를 실행한다. 판매자는 자기 범위 자료 읽기만 허용하고 완료·타 판매자 조회는 거부한다. 웹은 조회 결과를 판매자별로 구획해 소계와 전체 합계를 보여 주며 같은 결과를 브라우저 인쇄/PDF 저장에 쓴다. 전체·분류 일괄 완료 API는 만들지 않는다.

## 대안과 영향

- 기존 원천 테이블을 실시간 조인해 조회하고 완료 이력만 저장하면 초기 변경은 적다. 다만 분류 변경·수수료 입력·정정·원사건 멱등성과 완료 시점의 재현성이 약해져 R09와 S6의 불변 장부 검증이 어렵다.
- 권장안은 장부/완료 두 테이블과 결제·환불 확정 트랜잭션의 장부 쓰기, 관리자/판매자 읽기·완료 API가 필요하다. 기존 거래 원자료는 삭제·덮어쓰지 않는다. migration은 먼저 격리 DB에서 적용·역검증하고, 공유 개발 DB는 별도 승인 뒤 정확한 대상에만 적용한다.

## RED 시험·완료 조건

- 5월 1일 판매→5월 20일 완료→7월 1일 환불: 환불은 7월 발생, 5월 완료 불변, 5월 원주문·품목 링크.
- 결제/환불 사건 재처리와 관리자 수수료 요청 재시도에도 장부 중복 0.
- A 완료가 B/어울몰 완료 상태를 바꾸지 않음. A의 겹치는 완료 기간 거부. 판매자 역할의 완료·타 판매자 조회 403.
- 어울몰 발송 농가 상품은 원 생산 농가 상품 근거와 어울몰 발송/배송비 근거를 함께 표시.
- 전체/분류/개별 조회의 판매자별 소계·전체 합계가 DB와 인쇄 화면에서 동일. 지급액 자동 확정·송금은 없음.

## 미확정 사항

- 수수료의 오프라인 입력 주체·근거 형식과 과거 거래의 분류 스냅샷 재구성 가능 범위는 승인 시 확정한다. 실제 공급자 계약·수수료율·농가/어울몰 부담 분담은 이번 개발 범위가 아니다.
